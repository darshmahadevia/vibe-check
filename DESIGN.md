# Minimal base layout

The user explicitly chose a minimal layout and deferred visual improvements. Use a light background, readable dark text, green primary actions, ordinary borders, and responsive single-column content. Keep photo selection and results central. Avoid decorative assets and a separate marketing page.

The photo and weight charts use accessible labels. Tables show raw values and gaps. The breakdown opens by default at widths of at least 768 pixels. Mobile users can expand it.

The design detector's Arial warning is intentionally deferred under the user's base-first direction. No claim of a completed visual redesign is made.
