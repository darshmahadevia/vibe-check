# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User specified Next.js App Router, TypeScript, and Vercel Hobby. No database or app accounts.

## Users

People choosing music for a photographed moment. Hackathon judges can use anonymous basic mode. An allowlisted Premium teammate tests queue mode.

## Product purpose

Vibe Check selects a song for a photo and exposes the evidence, six mood parameters, weights, candidate scores, and winner comparison.

## Capabilities and constraints

Camera file input and upload share browser JPEG conversion at a maximum of 768 pixels. Gemma 4 proposes eight songs in one normal call. Code ranks songs. Spotify search verifies candidates anonymously. Browser PKCE enables queueing. Photos are never stored or logged by the app. Rooms, voting, accounts, databases, playlists, history, video, native apps, and payments are excluded.

## Brand commitments

The name is Vibe Check. The user requests a polished dark music workbench with dimensional sleeves, warm ember accents, and purposeful motion.
